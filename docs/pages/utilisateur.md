# Guide Utilisateur {#utilisateur}

## Présentation

La borne d'arcade de l'IUT du Littoral Côte d'Opale propose une sélection de jeux
open source accessibles depuis un menu interactif. Deux joueurs peuvent jouer
simultanément grâce aux deux joysticks et aux boutons de la borne.

## Contrôles

### Joueur 1

| Commande | Touche clavier |
|----------|---------------|
| Joystick haut | Flèche haut |
| Joystick bas | Flèche bas |
| Joystick gauche | Flèche gauche |
| Joystick droite | Flèche droite |
| Bouton A (bas gauche) | F |
| Bouton B (bas centre) | G |
| Bouton C (bas droite) | H |
| Bouton X (haut gauche) | R |
| Bouton Y (haut centre) | T |
| Bouton Z (haut droite) | Y |

### Joueur 2

| Commande | Touche clavier |
|----------|---------------|
| Joystick haut | O |
| Joystick bas | L |
| Joystick gauche | K |
| Joystick droite | M |
| Bouton A (bas gauche) | Q |
| Bouton B (bas centre) | S |
| Bouton C (bas droite) | D |
| Bouton X (haut gauche) | A |
| Bouton Y (haut centre) | Z |

> **Note** : L'encodeur clavier de la borne de l'IUT a été mal relié aux boutons
> d'origine. Les correspondances ci-dessus sont celles du mapping corrigé.

## Navigation dans le menu

1. **Parcourir les jeux** : Joystick haut/bas du joueur 1
2. **Lancer un jeu** : Bouton A du joueur 1
3. **Quitter le menu** : Bouton Z du joueur 1
4. Après avoir demandé à quitter, une confirmation s'affiche.
   Validez avec le bouton A du joueur 1.

> Après avoir quitté le menu, attendez **30 secondes** pour l'extinction complète
> de la machine.

## Jeux disponibles

### Jeux Java (MG2D)

- **Minesweeper** — Démineur classique avec 3 niveaux de difficulté.
  Bouton A pour creuser, Bouton B pour poser un drapeau.
- **Puissance X** — Variante du Puissance 4.
- **Columns** — Jeu de puzzle type colonnes (inspiré du jeu SEGA).
- **JavaSpace** — Shoot'em up spatial avec boss.
- **Snake Eater** — Jeu du serpent.
- **Pong** — Le classique du jeu d'arcade, 2 joueurs.
- **InitialDrift** — Jeu de course / drift.
- **DinoRail** — Reproduction du jeu Chrome Dino.
  Joystick haut pour sauter, bas pour s'abaisser.
- **Kowasu Renga** — Casse-briques.

### Jeux Python (Pygame)

- **TronGame** — Course de Light Cycles inspirée du film Tron.
  Mode solo contre IA ou 2 joueurs. 3 niveaux de difficulté.
- **PianoTile** — Jeu de rythme musical type Piano Tiles.
- **OsuTile** — Jeu de rythme inspiré d'osu!.
- **Ball Blast** — Tirez sur des balles qui rebondissent pour les détruire.

### Jeux Lua (LÖVE 2D)

- **CursedWare** — Collection de mini-jeux rapides dans le style WarioWare.
  Inclut : BroForce, DriftDrawer, PPAP, ShotMaster.
